# 01 — de Casteljau 算法与 Bezier 求值

## 要解决的问题

给定控制顶点 P0..Pn 和参数 t ∈ [0, 1]，求 Bezier 曲线上的点 B(t)。

## 核心直觉：反复做线性插值

两点线性插值 `lerp(P, Q, t) = (1-t)·P + t·Q` 就是"沿线段按比例 t 走到某处"。

de Casteljau 把求值变成一座三角形：对当前层的每对相邻点做 lerp，得到下一层，
每层少一个点，最后剩下的唯一一个点就是 B(t)。

```
P0    P1    P2    P3          <- level 0（控制多边形）
  Q0    Q1    Q2              <- level 1
    R0    R1                  <- level 2
       B(t)                   <- level 3（答案）
```

## 手算示例（与脚本输出一致）

控制点 (0,0), (1,2.2), (3,2.2), (4,0)，t = 0.35：

| level | 中间点 |
|-------|--------|
| 0 | (0, 0), (1, 2.2), (3, 2.2), (4, 0) |
| 1 | (0.35, 0.77), (1.7, 2.2), (3.35, 1.43) |
| 2 | (0.8225, 1.2705), (2.2775, 1.9305) |
| 3 | **(1.33175, 1.5015)** |

## 与 Bernstein 定义式的关系

定义式：`B(t) = Σ C(n,i)·t^i·(1-t)^(n-i)·P_i`

- de Casteljau 是这个和式的**嵌套分解**（类似多项式求值的 Horner 法），
  两者在数学上完全等价，脚本对拍误差 2.22e-16（机器精度）。
- 但直接算定义式要处理大组合数 × 小数幂的相消，数值不稳定；
  de Casteljau 全程只有加法和乘法，误差可控。**内核选它的原因就在这。**

## 关键性质（都能从 lerp 结构直接看出来）

1. **端点插值**：B(0)=P0，B(1)=Pn（t=0/1 时三角形一层层退化回端点）。
2. **凸包性**：每个 lerp 点都在上一层的凸包内 ⇒ 整条曲线在控制多边形的凸包里。
3. **仿射不变性**：lerp 与仿射变换可交换 ⇒ 平移/旋转曲线 = 平移/旋转控制点。
4. **端点切向**：曲线在 P0 处与 P0P1 相切，在 Pn 处与 Pn-1Pn 相切
   （t=0 时 level 1 的第一个点就落在 P0P1 上）。

## 与内核的联系

内核求值用的就是"反复 lerp"这个思想；下一步的 **de Boor 算法**是它的推广——
把 Bezier 的"整条边全局混合"换成 B 样条"只在局部支撑区间内混合"，
代价是要先理解节点向量。
